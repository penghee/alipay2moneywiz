📊 整体结构：2个核心工作表（Sheets）
工作表名   用途   更新频率
Snapshot（截面快照）   记录每月净资产水位   每月1次

Flow（资金流）   记录收入、支出大类、其他项   每月1次（月底批量导入）

✅ 所有日常消费无需手动录入，月底从支付宝/微信/信用卡导出后粘贴到 Flow 表即可。

二、Flow 表：资金流入流出记录

A. 字段设计（CSV 列头）

日期,类型,子类,金额,来源/去向,备注

B. 填写规则说明
字段   说明   示例
日期   交易发生日或还款日   2026-03-28

类型   固定三类：收入 / 支出 / 其他项   收入

子类   按你的框架细化   工资收入、餐饮外卖、股票亏损

金额   正数（收入为正，支出/损失也为正！）   15000

来源/去向   钱从哪来/到哪去   公司A、招商银行信用卡

备注   可选补充   Q1奖金、换手机

💡 关键设计：  
所有金额均为正数，通过“类型”区分方向；  
这样便于分类汇总，避免正负混淆。

D. 如何高效填充 Flow 表？

月底导出账单：
   支付宝：账单 → 筛选“支出” → 导出Excel
   信用卡APP：下载月度明细（通常含商户分类）

批量转换格式（用Excel或Google Sheets）：
   将原始账单中的“支出”行复制过来；
   在“类型”列填“支出”；
   用“查找替换”将商户名归类到你的子类（如“星巴克”→“餐饮外卖”）；
   删除无关列，保留日期、金额、分类。

收入和其他项：手动添加几行即可（通常每月不超过5笔）。

三、自动化分析（可选但推荐）

在 Excel 中新建一个 Dashboard 工作表，用简单公式实现：

// 本月总收入
=SUMIFS(Flow!D:D, Flow!B:B, "收入")

// 本月总支出
=SUMIFS(Flow!D:D, Flow!B:B, "支出")

// 净现金流（不含投资波动）
=总收入 - 总支出

// 净资产变化（来自Snapshot）
=当前月净资产 - 上月净资产

再加一个折线图，就能一眼看出：
是消费超支？还是投资亏损导致净资产下降？
